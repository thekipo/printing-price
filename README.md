# Ценники Step Up

Десктоп-приложение для печати ценников на термопринтере Xprinter XP-365B (TSPL), этикетка 60×40 мм.

## Возможности

- Список ценников: модель, цена, старая цена (акция), размер, номер полки, кол-во копий
- Живое превью этикетки при заполнении формы
- Поиск по списку (по любому слову или их сочетанию)
- Пачечная печать с возможностью остановить в процессе
- Список сохраняется между запусками (`tags_list.json`)

## Установка

```bash
pip install -r requirements.txt
```

Также нужен системный шрифт с кириллицей (обычно уже есть):

```bash
sudo dnf install liberation-sans-fonts dejavu-sans-fonts
```

## Запуск

```bash
python3 app.py
```

Устройство принтера по умолчанию — `/dev/usb/lp0`, меняется прямо в приложении.

## Windows

Тот же код работает и на Windows: печать идёт через спулер на выбранный
принтер (вместо пути к устройству — выпадающий список принтеров Windows).
Как настроить видимость принтера в Windows и собрать `.exe` — см.
[BUILD_WINDOWS.md](BUILD_WINDOWS.md).

## Файлы

- `app.py` — десктоп-интерфейс (CustomTkinter)
- `price_tag.py` — рендер этикетки и кроссплатформенная печать через TSPL
- `build_exe.bat` — сборка `.exe` на Windows (см. BUILD_WINDOWS.md)
- `tags_list.json` — сохранённый список ценников (создаётся автоматически, в git не попадает)
