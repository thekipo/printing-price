# Windows: принтер, .exe и запуск

Один и тот же код (`app.py`, `price_tag.py`) работает и на Linux, и на Windows —
приложение сам определяет ОС и печатает по-разному:

- **Linux** — пишет TSPL-байты прямо в файл устройства (`/dev/usb/lp0`).
- **Windows** — отправляет их через спулер Windows на выбранный принтер
  (задание типа `RAW`, без обработки драйвером). Для этого в форме приложения
  вместо поля "Устройство принтера" появляется выпадающий список принтеров,
  установленных в Windows.

## Шаг 1. Сделать так, чтобы Windows видела принтер

1. Подключите Xprinter XP-365B по USB и включите его.
2. **Параметры → Bluetooth и устройства → Принтеры и сканеры → Добавить устройство.**
   Если Windows определит принтер сама — отлично, переходите к шагу 2.
3. Если не определила: **"Нужный принтер отсутствует в списке" → "Добавить
   локальный принтер или принтер с сетевым подключением с параметрами,
   заданными вручную"** → выберите порт `USB00X` (появится в списке, если
   принтер подключён и включён).
4. Драйвер:
   - если производитель Xprinter даёт драйвер под XP-365B — поставьте его
     (Windows Update иногда находит сам, либо драйвер с сайта производителя);
   - если драйвера нет — выберите **Generic → Generic / Text Only**. Это
     нормально: наше приложение сам печатает TSPL-командами как задание
     `RAW`, драйвер тут не форматирует текст, а просто передаёт байты.
5. Дайте принтеру понятное имя, например `XP-365B`, завершите добавление.
6. Проверьте: принтер должен появиться в **Панель управления → Устройства и
   принтеры**.

После этого он появится и в выпадающем списке в приложении — там кнопка
"Обновить список принтеров", если подключили принтер после запуска программы.

## Шаг 2. Собрать .exe

Нужен Python 3.11+ с Windows (python.org, при установке отметить
"Add python.exe to PATH").

1. Скопируйте папку проекта на Windows-машину.
2. Запустите `build_exe.bat` (двойным кликом или из консоли).
   Скрипт сам создаст виртуальное окружение, поставит зависимости
   (включая `pywin32` для печати) и соберёт exe через PyInstaller.
3. Готовый файл — `dist\Cenniki_StepUp.exe`. Его можно скопировать куда
   угодно и запускать без Python — все зависимости уже внутри.

## Проверка

Запустите `Cenniki_StepUp.exe`, в поле "Принтер" выберите `XP-365B` (или как
вы его назвали), добавьте тестовый ценник и нажмите "Печать выбранных".
Если ничего не печатается — откройте **Очередь печати** этого принтера в
Windows: если задание "зависло" там, значит порт/драйвер выбран неверно на
шаге 1 (попробуйте другой порт USB00X или Generic/Text Only).

## Список ценников на Windows

Файл `tags_list.json` сохраняется рядом с exe (или рядом с `app.py`, если
запускаете не из exe) и переживает перезапуск — так же, как на Linux.
